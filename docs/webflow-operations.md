# Webflow operations

The DevKit CLI supports local development/building and read-only Webflow component or rendered
script inspection. It does not apply custom code or publish a Webflow site.

Use the official Webflow MCP 2.0.1 server for remote Designer, CMS, custom-code, Agent Instruction,
and publication work. Load the matching focused skill and follow:

```text
inspect -> plan -> confirm -> apply -> read back -> verify
```

Preserve unrelated state, keep publication separate from editing, and stop on unresolved IDs,
bindings, permissions, modes, scope, or pre-state drift. Site identifiers and tokens belong in the
connected OAuth session or ignored local environment, never in reusable source.
