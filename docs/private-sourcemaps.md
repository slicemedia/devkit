# Private production sourcemaps

```sh
slicemedia-devkit build --sourcemap
```

The default build remains unchanged. This opt-in mode generates JavaScript sourcemaps for
debugging while separating them from the files deployed to Webflow's asset host:

```text
dist/
  addons/
    counter.js
    slider.js
    slider.css                        # only when this entry imports CSS
  webflow-scripts.json
.slicemedia/sourcemaps/
  .gitignore
  counter.js.<bundle-hash>.<map-hash>.map
  slider.js.<bundle-hash>.<map-hash>.map
```

Maps are extracted before the bundler writes its output. The production script has no
`sourceMappingURL` reference or embedded map. Vite's `hidden` setting alone would still put a map
beside the script; DevKit also removes that map from the output and stores it separately.

Deploy only `dist/`. Do not upload the repository root or `.slicemedia/`. Source maps contain
original source text and must be retained in private build storage if they are kept in CI. The CLI
reports their paths; `--json` returns `sourceMapPaths` on each built entry. The bundle hash identifies the exact built
JavaScript the map belongs to. Repeated builds retain earlier maps for debugging older releases.

The private directory receives a local ignore rule. DevKit rejects overlapping output/private
paths and symlinked private storage, creates new private files with restrictive POSIX modes, and
does not copy maps into the deployable directory. Keep private build storage access-controlled on
the host and in CI. The normal dev server also denies requests to this private directory.

Use the matching map with a local debugger or an explicitly configured private error-monitoring
service. A map from a different build can point to incorrect source locations. CSS production maps
are not generated by this option.

Keeping maps private prevents publishing the original sources through those files. It does not
make browser code secret: visitors still download and can inspect the production JavaScript.

Reference: [Vite sourcemap behavior](https://vite.dev/config/build-options.html#build-sourcemap).
