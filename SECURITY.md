# Security Policy

Report suspected vulnerabilities privately to the repository owner. Do not open a public issue
while this repository is private.

- Keep Webflow OAuth data, site IDs, deployment credentials, and targets out of source control.
- Use official Webflow MCP permissions and explicit confirmation for remote writes or publication.
- Keep credentialed deployment out of DevKit. Report Spaces Deployer issues in its independent
  private repository.
- Scan source, generated adapters, bundles, archives, package tarballs, logs, and Git history before
  release.
